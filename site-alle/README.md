# Site Allê Ebrahim

Projeto separado do cartão digital (pasta pai). Aqui fica o site institucional completo da Allê, modelado a partir de https://felipepereira.net/ com a identidade visual dela.

## Rodar

```bash
npm install
npm run dev   # http://localhost:3100
```

## Stack

Mesma do cartão: Next.js 16.4.2, React 19.3.1, TypeScript e Tailwind 4. Fonte Fira Sans. Cores em `public/brand/cores.css`.

## Estrutura planejada (modelo do site de referência)

- Início: topo com chamada e botão, "Quem é Allê Ebrahim" (conquistas + foto + carrossel), "Como posso te ajudar" (3 cards), cases/depoimentos, chamada para o WhatsApp, redes sociais e rodapé.
- Páginas: Allê Ebrahim (sobre), Treinamentos, Mentoria, Palestras, Cases, Depoimentos, Contato.

## Assets

`public/brand/` já traz logos, catavento e patterns copiados de `../Alle-brand-assets`.
